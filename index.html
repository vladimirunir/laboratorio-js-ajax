Aprender los fundamentos construyendo.

Este proyecto reúne ejercicios prácticos de JavaScript y una demostración de comunicación asíncrona mediante XMLHttpRequest. El código está separado por responsabilidades para facilitar su lectura, mantenimiento y ampliación.
